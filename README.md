Antenna jelszint mérő.
A projekt föld felszíni antenna jelerősségét méri.
Menü gomb hosszabb nyomására előjön a menü ami 3 részből ál.
1 Kontraszt állítás.
2 hang jelzés ki/be kapcsolása ami a térerő szint változással változik.
3 Jelszint vétel érzékenység állítása.
Fel/le gombokkal az értékek változtatása.
Újabb menü gomb nyomásra vissza lép a fő képernyőre.
Az áramkőr egy bizonyos 10 perc tétlenségi idő után kikapcsolja a kijelzőt, de bármely gomb megnyomásra ismét bekapcsolja.
A hang jelző Buzzer nem belső generátoros, tehát a PIC18F14K22-es chip állítja elő.
